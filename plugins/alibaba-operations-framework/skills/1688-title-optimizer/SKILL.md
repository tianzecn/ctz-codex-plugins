# 1688 商品标题优化流程

## 定位

这是给运营团队重复使用的 Production 级标题工作流。它只负责把用户提供的类目、关键词、竞品标题和禁用词整理成可发布前讨论的标题方案，不承诺搜索排名、曝光、询盘或成交结果。

## 输入

优先收集 4 类信息：

1. 商品类目：商品所属 1688 类目或运营口径。
2. 核心关键词：必须覆盖的品类词、属性词、场景词或服务词。
3. 竞品标题：用户提供的竞品标题原文，可为多个。
4. 禁用词：品牌词、侵权词、夸大词、平台限制词或内部约定不能使用的词。

如果缺少商品类目或核心关键词，先追问。竞品标题或禁用词缺失时可以继续，但必须在输出中标注“未提供竞品标题”或“未提供禁用词，风险检查不完整”。

## 流程

### 1. 拆解输入

- 从商品类目中确认标题主体，不跨类目混写。
- 将核心关键词分成品类词、属性词、场景词、服务词。
- 从竞品标题中只提取通用类目词、属性词和场景表达，不照搬整句，不使用竞品品牌词。
- 将禁用词作为硬约束，标题方案中不得出现。

### 2. 组装标题

默认生成 3 个标题方案：

- 稳健覆盖版：优先覆盖核心品类词和关键属性，适合日常发布。
- 长尾精准版：面向细分属性、场景或规格，适合测款和补充搜索覆盖。
- 场景转化版：强调采购场景、使用对象或真实服务优势，适合非标、批发、定制或供货型商品。

标题应尽量清楚、自然、可读。不要为了塞词重复堆叠同义词，不要加入用户没有提供且无法确认的材质、认证、品牌、型号、产地或服务承诺。

### 3. 检查覆盖

对每个标题说明：

- 覆盖了哪些核心关键词。
- 借鉴了哪些竞品通用表达。
- 哪些关键词没有覆盖，以及未覆盖原因。
- 哪些词需要用户确认真实商品事实后才能使用。

### 4. 检查风险

重点提醒 4 类风险词：

- 禁用词命中：用户明确提供的禁用词或近似变体。
- 绝对化和夸大词：第一、最、全网最低、爆款、必卖、稳赚等。
- 侵权和蹭词：品牌名、IP、明星、平台名、竞品名、非本商品词。
- 无证据资质词：认证、专利、环保、食品级、医用、阻燃等。

涉及平台处罚、广告法、禁售或类目准入的判断，只给风险提醒，不做最终合规裁定。最终以当前 1688 后台、规则中心和法务审核为准。

## 输出格式

按以下结构输出，保持简洁，便于运营团队复制到工作表或群里评审：

1. 输入判断：说明类目、核心关键词、竞品标题、禁用词是否齐全。
2. 关键词拆解：列出品类词、属性词、场景词、服务词，并标注来源。
3. 标题方案：给出 3 个标题，每个标题包含版本定位、标题文本、主攻词、适用场景。
4. 关键词覆盖说明：逐条说明每个标题覆盖和未覆盖的关键词。
5. 风险词提醒：列出已命中风险、需确认风险和建议替换词。

## 边界

- 不写详情页文案、卖点段落、主图文案或客服话术。
- 不做图片生成、主图设计、视觉排版或素材建议。
- 不编造搜索热度、竞品销量、后台诊断结果或平台推荐词。
- 不提供刷词、堆词、低价假 SKU、错放类目或侵权蹭品牌方案。
- 不把竞品标题直接改写成自己的标题；只能抽取通用词路和表达结构。

## 示例

用户输入：

- 商品类目：搬家袋
- 核心关键词：搬家袋、收纳袋、大容量、牛津布、批发
- 竞品标题：大容量牛津布搬家袋收纳打包袋批发现货；加厚行李收纳袋搬家打包袋厂家直发
- 禁用词：全网最低、爆款、宜家

输出标题方案示例：

1. 稳健覆盖版：大容量牛津布搬家袋 收纳打包袋 批发现货
2. 长尾精准版：加厚牛津布搬家袋 行李收纳打包袋 厂家批发
3. 场景转化版：搬家打包收纳袋 大容量牛津布行李袋 批发供货

然后说明每个标题覆盖了哪些核心词，哪些词来自竞品通用表达，并提醒“牛津布”“加厚”“厂家”需要商品事实支持；禁用词不得使用。
